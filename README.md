# maple

Full-stack developer. I build backend services, ML pipelines, and an unreasonable
amount of game modding and reverse-engineering tooling. Linux daily driver.

## Selected work

- **[umamusume_apworld](https://github.com/maplehugs/umamusume_apworld)** — Archipelago multiworld randomizer for Umamusume: Pretty Derby
- **[PD2-Criminal-Dawn](https://github.com/maplehugs/PD2-Criminal-Dawn)** — PAYDAY 2 multiworld roguelite mod, powered by archipelago.gg
- **[SkinShare_Gmod](https://github.com/maplehugs/SkinShare_Gmod)** — Garry's Mod addon: share Workshop playermodels with every player mid-game, no restart
- **[ai_transcription](https://github.com/maplehugs/ai_transcription)** — transcription web app with speaker diarization (Whisper + NeMo)
- **[neural-network-austral](https://github.com/maplehugs/neural-network-austral)** — stockout forecasting with GRU, Croston/SBA benchmarks and Monte Carlo simulation
